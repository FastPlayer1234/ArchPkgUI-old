# ArchPkgUI

**This application is being replaced by one using notcurses and C for better performance and compatability on computers without a GUI**
**ArchPkgUI** is a lightweight and user-friendly package manager frontend for Arch Linux. It provides a simplified interface to manage packages using `alpm`.

## Features

- List and Update all installed packages
- Update package databases
- List packages that need updates
- Clean and minimal GUI

## Future features
- Search for packages
- View detailed package information
- Install and remove packages
